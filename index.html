NEED TO KNOW

Frequently asked questions

Are my projects private?

This frontend is designed around private-by-default project controls. Real privacy and enforcement require a secure backend.

How do PIN-protected links work?

A recipient enters the configured PIN before opening a shared project. This demo only simulates that flow in your browser.

How do collaborator permissions work?

Choose Viewer or Editor access when setting up a share. Server-side enforcement will be needed for production use.

Does this demo execute code?

No. The interface previews the workflow, but code execution is not connected in this frontend build.

Can I import a GitHub repository?

The GitHub page demonstrates the import experience. OAuth and repository transfer require backend integration.
